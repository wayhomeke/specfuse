## Context

SpecFuse scaffolder generates project configuration files via template functions in `src/templates/`. The scaffolder (`src/scaffolder.ts`) orchestrates file creation in sequence: `.gitignore` → `CLAUDE.md` → `.claude/settings.local.json` → `openspec/config.yaml` → git init → openspec init → codegraph init.

Skills in Claude Code are auto-discovered from `.claude/skills/<name>/SKILL.md` files. The existing openspec-* skills are generated by `openspec init --tools claude`, not by the scaffolder itself.

## Goals / Non-Goals

**Goals:**
- Add `composeGrillMeSkill()` template function returning SKILL.md content
- Generate `.claude/skills/grill-me/SKILL.md` during scaffolding
- Skip generation if file already exists (protect user customizations)
- Keep skill content lightweight — activate mode + reference CLAUDE.md rules

**Non-Goals:**
- No StackProfile dependency (skill is universal)
- No modification to openspec init behavior
- No duplication of the full grill protocol in SKILL.md

## Decisions

### 1. New template file: `src/templates/grill-me-skill.ts`

Export `composeGrillMeSkill(): string`. Returns complete SKILL.md content with YAML frontmatter + markdown body.

**Rationale:** Follows existing pattern (one template file per output type). No stack parameter needed since grill review is universal.

### 2. Insertion point in scaffolder

Write the skill file after `.claude/settings.local.json` (since it's in the same `.claude/` directory) and before OpenSpec/Git init steps. Use `readTextSafe()` to check existence first — skip if file already present.

**Rationale:** Consistent with existing "don't overwrite" pattern used for `openspec/config.yaml`. Placing it with other `.claude/` writes keeps the scaffolder logic grouped.

### 3. SKILL.md content strategy

The skill body:
- Declares its trigger (when to use)
- Lists the protocol steps as a concise checklist
- References "Pre-Apply Review (Grill) section in CLAUDE.md" as the authoritative source
- Does NOT repeat the full blocking categories, dimensions, or summary format

**Rationale:** Single source of truth in CLAUDE.md. If we duplicated the full protocol, any update to CLAUDE.md template would need a parallel update in the skill template.

## Risks / Trade-offs

- **[Skill drift]** If user edits CLAUDE.md grill section but not the skill, they could diverge → Mitigation: skill explicitly says "follow CLAUDE.md rules", so it always defers.
- **[Discovery]** User might not know `/grill-me` exists → Mitigation: the CLAUDE.md trigger prompt already suggests running it.
